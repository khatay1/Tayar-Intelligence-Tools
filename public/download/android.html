English

How to download and install

  1. Tap the Android download button above.
  2. Open the downloaded APK file.
  3. If Android asks, allow installs from this browser or Files app.
  4. Tap Install, then open Tayar Tools.

Svenska

Så laddar du ner och installerar

  1. Tryck på Android-knappen ovan för att ladda ner.
  2. Öppna den nedladdade APK-filen.
  3. Om Android frågar, tillåt installation från webbläsaren eller appen Filer.
  4. Tryck på Installera och öppna sedan Tayar Tools.

العربية

كيفية التنزيل والتثبيت

  1. اضغط زر تنزيل Android الموجود بالأعلى.
  2. افتح ملف APK بعد اكتمال التنزيل.
  3. إذا طلب Android، اسمح بالتثبيت من المتصفح أو تطبيق الملفات.
  4. اضغط تثبيت، ثم افتح Tayar Tools.
