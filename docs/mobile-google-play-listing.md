# Tayar Tools — Google Play listing draft

Prepared for the React Native mobile release candidate. Google Play currently limits the app name to 30 characters, the short description to 80 characters, and the full description to 4,000 characters.

## English

**App name**
Tayar Tools

**Short description**
AI and productivity tools for writing, files, websites, images and code.

**Full description**
Tayar Tools brings AI and practical productivity workflows into one mobile workspace.

Use the same Tayar account across supported web, Android and iOS experiences. Work with writing and AI-assisted tasks, document and PDF utilities, image workflows, website projects, code assistance and other productivity tools from a mobile-first interface.

Selected file workflows are processed on-device whenever the tool supports local processing. Tayar also includes account controls, legal links and permanent account deletion from the mobile profile.

Highlights:
• AI-assisted productivity and writing workflows
• PDF, document and image utilities
• Website and code project tools
• Shared Tayar account access across supported platforms
• Local processing for supported file workflows
• Permanent in-app account deletion
• Privacy Policy and Terms available before and after sign-in

Tayar Tools does not require camera or microphone access for its current workflows.

Support: https://tayar.se/support.html
Privacy: https://tayar.se/#privacy
Account deletion: https://tayar.se/account-deletion

## Swedish

**App name**
Tayar Tools

**Short description**
AI- och produktivitetsverktyg för text, filer, webb, bilder och kod.

**Full description**
Tayar Tools samlar AI och praktiska produktivitetsflöden i en mobil arbetsyta.

Använd samma Tayar-konto i de web-, Android- och iOS-upplevelser som stöds. Arbeta med text och AI-assisterade uppgifter, dokument- och PDF-verktyg, bildflöden, webbprojekt, kodassistans och andra produktivitetsverktyg i ett mobilanpassat gränssnitt.

Höjdpunkter:
• AI-assisterade produktivitets- och textflöden
• PDF-, dokument- och bildverktyg
• Verktyg för webb- och kodprojekt
• Samma Tayar-konto på plattformar som stöds
• Lokal bearbetning för filflöden som stöds
• Permanent kontoradering i appen
• Integritetspolicy och villkor före och efter inloggning

Tayar Tools behöver inte kamera- eller mikrofonåtkomst för de nuvarande arbetsflödena.

Support: https://tayar.se/support.html

يجمع Tayar Tools أدوات الذكاء الاصطناعي وسير العمل الإنتاجي العملي في مساحة عمل مخصصة للجوال.

• حذف الحساب نهائيًا من داخل التطبيق

لا يحتاج Tayar Tools إلى صلاحية الكاميرا أو الميكروفون في سير العمل الحالي.
